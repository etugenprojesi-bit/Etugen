# Draft: ECOCROP reuse question to FAO

**To:** copyright@fao.org
**Subject:** Reuse terms for ECOCROP crop parameters in an open-source, non-commercial hackathon project

---

Dear FAO Copyright and Licensing team,

We are a team taking part in the NASA Space Apps Challenge 2026
(14–15 November 2026). We are building a free, open-source (Apache-2.0)
decision-support web app that helps farmers explore crop-rotation options using
NASA Earth observation data. The app is non-commercial and contains no
advertising.

We would like to use crop environmental requirements from the ECOCROP database
(now offered through GAEZ: https://gaez.fao.org/pages/ecocrop): for each of
about 35 crops, the optimal and absolute temperature and rainfall ranges and
the length of the growing season. We would store these values in a small table
inside our public code repository, with full attribution to FAO and a link to
ECOCROP.

We could not find a licence statement for the ECOCROP data itself. The FAO
Database Terms of Use (CC BY 4.0) mention statistical databases such as
FAOSTAT, and the GAEZ v4 documentation is CC BY-NC-SA 3.0 IGO.

Could you please tell us:

1. Which licence or terms apply to the ECOCROP crop parameter data?
2. May we redistribute a subset of the parameters (about 35 crops, around
   10 numeric fields each) in a public repository under those terms, with
   attribution?
3. What attribution or citation wording would you like us to use?

Because the event is on 14–15 November, a short reply before then would help
us a lot. Until we hear from you, we will not use ECOCROP data and will use
values from published literature instead.

Thank you for your time and for maintaining these resources.

Kind regards,
