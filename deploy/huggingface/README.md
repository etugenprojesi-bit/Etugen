# Etügen

NASA Space Apps Challenge 2026, *Field Shift: Adapting Farms with NASA Data*.

A phone web app that turns 25 years of NASA data (POWER, GPM IMERG, SMAP, MODIS,
NASADEM) into a plain crop-rotation plan for any field. Turkish interface by default;
press **EN** in the header, or open the address with `?lang=en`, for English.

Try the three demo fields (Konya, Punjab, Nakuru) for the fastest results. This tool
supports, it does not replace, the farmer’s judgement and local expertise.

Code, method and data sources: see the project’s GitHub repository (Apache-2.0).
